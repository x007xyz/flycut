# fly-cut

## 简介
基于Webcodecs + Vue3实现的Web端剪辑工具 <br/>
如果有用请 🌟 Star 🌟 支持一下哟 🫣 <br/>

[打开 FlyCut 编辑器](https://flycut.co)

## 功能
![](coverImage/map.png)

FlyCut 会自动在当前浏览器中保存最近一次的时间轴和导入素材。重新打开同一站点即可继续编辑；清除站点数据会删除本地草稿。
